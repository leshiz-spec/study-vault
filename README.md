# StudyVault 前端 Demo

这是一个无需后端即可体验的 StudyVault（个人知识库）可点击前端演示。数据会保存在浏览器 `localStorage` 中。

## 本地运行

直接打开 `index.html`，或在当前目录启动任意静态文件服务器：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 已覆盖的演示流程

- 总览 Dashboard：笔记、收藏、标签、学习活动统计
- 全部笔记 / 我的收藏 / 回收站切换
- 标题与正文搜索、标签筛选、笔记详情查看
- 新建笔记、收藏切换、移入回收站与恢复
- AI 助手按钮、快捷键提示、新建标签弹窗
- 设置页与响应式布局
